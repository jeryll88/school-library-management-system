# Suggested Improvements for Future Updates

| Suggestion | Description | Benefit |
|------------|-------------|---------|
| **Book Cover Images** | Load book covers using Open Library Covers API (`https://covers.openlibrary.org/b/isbn/{isbn}-M.jpg`) or allow image upload. | Greatly improves visual appeal on student and admin catalogs. |
| **Borrowing Quota** | Limit students to a maximum of 3 (or configurable) simultaneously borrowed books. | Prevents hoarding and ensures fair book availability. |
| **Due Date Reminders** | Add an alert on the student dashboard when a book is due in less than 48 hours. | Reduces overdue loans and late returns. |
| **CSV / Excel Export** | Add an "Export to CSV" button for Borrowing History and Book Inventory. | Useful for library audits and school reporting. |

*These items have been partially implemented in the current codebase (cover images, quota, due‑soon alerts, CSV export). The list serves as a roadmap for polishing and extending the functionality further.*
